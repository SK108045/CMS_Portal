# Mission School Financial Accountability Platform

A local-first school financial management system built with React, TypeScript and Vite; ASP.NET Core Web API; Entity Framework Core; and PostgreSQL.

The working application is in **[school-management/](school-management/)**.

See **[setup and run instructions](school-management/README.md)** for Ubuntu and Windows development, database setup, migrations, demo accounts, tests, and self-contained Windows publishing.
